# 카카오톡 PC 메시지 생성기

카카오톡 PC(Windows) 버전의 채팅 화면을 그대로 재현해서 가상의 대화 이미지를 만들 수 있는 웹 도구입니다.
설치나 서버 없이 `index.html` 파일 하나로 동작합니다.

> **비공식 프로젝트입니다.** 카카오와 관련이 없으며, "카카오톡"은 카카오의 상표입니다.

## 특징

- 실제 카카오톡 PC 캡처를 픽셀 단위로 측정해서 맞춘 UI (말풍선 크기, 모서리, 꼬리, 간격, 색상, 글자 크기)
- 같은 사람이 연속으로 보낸 메시지는 자동으로 묶이고, 같은 분(分)이면 마지막 말풍선에만 시간 표시
- 내 메시지 / 상대 메시지 / 날짜 구분선 추가, 수정, 삭제, 순서 변경
- 안 읽음 "1" 표시
- 상대 이름, 프로필 사진, 배경색 변경
- PNG 저장 (1배 / 2배 / 3배)
- 작업 내용은 브라우저에 자동 저장

## 사용 방법

1. `index.html`을 브라우저로 엽니다.
2. 상대 이름과 프로필 사진을 설정합니다.
3. 보내는 사람(나 / 상대 / 날짜)과 시간을 고르고 메시지를 입력한 뒤 Enter 또는 **추가**를 누릅니다.
4. 목록에서 보내는 사람 버튼을 누르면 나 → 상대 → 날짜 순서로 바뀝니다.
5. **PNG로 저장**을 누릅니다. 1배는 실제 카톡 캡처와 같은 크기입니다.

### GitHub Pages로 배포하기

1. 저장소에 `index.html`을 올립니다.
2. **Settings → Pages** 에서 Branch를 `main` / `(root)`로 선택하고 저장합니다.
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

## 글꼴 (맑은 고딕)

실제 카카오톡 PC는 **맑은 고딕**을 사용합니다.

- Windows에서는 설치된 맑은 고딕이 자동으로 사용됩니다.
- macOS, Linux 등에서는 편집 패널의 **글꼴**에서 본인이 가진 `malgun.ttf`를 직접 선택하면 그 브라우저에서만 적용됩니다.
- 맑은 고딕은 마이크로소프트의 글꼴이므로 이 저장소에는 **포함되어 있지 않습니다.** 글꼴 파일을 저장소에 올리지 마세요.

## 한계

- 글자 렌더링은 실제 카톡(ClearType)과 달라서, 크게 확대하면 글자 가장자리 색이 조금 다릅니다.
- 프로필 사진 모서리는 실제와 거의 같지만 완전히 같지는 않습니다.
- 이모티콘, 사진, 파일, 답장, 모바일 버전은 아직 지원하지 않습니다.
- PNG 저장은 [html2canvas](https://github.com/niklasvh/html2canvas)를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 사용 시 주의

이 도구는 창작물, 패러디, 디자인 목업, 스토리 제작 등을 위한 것입니다.
만든 이미지를 실제 대화인 것처럼 속이거나, 타인을 사칭하거나, 증거로 제출하는 등 **기만 목적으로 사용하면 안 됩니다.**
사용에 따른 책임은 사용자에게 있습니다.
